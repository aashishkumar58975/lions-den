# Lions Den Gym — Frontend Template

A professional gym website template built with:

- React + TypeScript
- Vite
- GSAP + ScrollTrigger
- Lucide React
- Responsive CSS

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

## Important: replace these placeholders

Search in `src/App.tsx` for:

- `RANCHI'S FITNESS DESTINATION`
- `500+`
- `20+`
- `TRAINER NAME`
- `+91 99999 99999`
- `Replace with Lions Den's complete address`
- Membership plan details
- Gallery image URLs

The enquiry form is currently frontend-only and shows a demo success message. Later it can be connected to a FastAPI/Supabase backend.

## Image note

The template currently uses Unsplash image URLs so the project works without local image files. For the final client website, replace them with Lions Den's real gym photographs.
